Strafe Mode-Onlineshop

Inhalt
  src/            Quellcode der Seite
  public/         Bilder, Videos und Fonts
  package.json    Abhängigkeiten
  astro.config.mjs

Der Ordner node_modules ist nicht enthalten und wird
beim ersten Befehl automatisch angelegt.

Projekt starten
  npm install      Abhängigkeiten installieren
  npm run dev      Entwicklungsserver, Adresse erscheint im Terminal
  npm run build    Build in den Ordner dist
  npm run preview  fertigen Build im Browser ansehen

Vorausgesetzt wird Node.js ab Version 18.
Der Shop ist außerdem online unter strafe.site erreichbar.
